# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 主变压器口径（v2）

主变压器的领域逻辑集中在 `frontend/src/domain/transformer/`，列表、详情面板、运营概览、
导出清单、缺陷联动读的是同一份台账：

- **告警复位一次办齐**：活动告警置「已复位」留痕（记录不删除）、油温/绕组温度回落到试验
  基准值并清掉越限红标、关联的设备缺陷置「已消除」、主变回到运行中。重复复位直接拒绝，
  告警台数不会减两次。停运检修会带着活动告警先复位留痕，检修回来不挂旧标记。
- **告警台数只有一个口径**：活动告警数（状态为告警或存在活动告警记录），列表页统计卡与
  运营概览的「异常量」都从这一处派生。
- **历史告警回填**：老数据一次性迁移到 v2（版本标记 `hydropower-plant-om:data-version`），
  告警记录按试验日期回填告警/复位时间；早期只有告警时间、没有处理人的记录处理人留空，
  在详情面板显示「待补录」并由值班人员补录，系统不伪造实名，补录一次即锁定，不改写在册结论。
- **缺陷分级沿用三级**：危急缺陷（油温 ≥95℃ 或 绕组温度 ≥115℃）、严重缺陷（任一温度越限：
  油温 ≥85℃、绕组温度 ≥105℃ 但未达危急线）、一般缺陷。发布告警联动生成缺陷并在
  「缺陷处置」页面（另一个入口）可见，编号沿用 `DEFE-` 序号、老数据不重编号。
- **导入去重与判重**：台账按 `变压器编号`（trim 后精确匹配）判重，已存在则更新、不存在则
  新增；文件内重复编号以最后一行为准。导入明细必须含全部台账列，且温度与状态口径一致
  （越限温度不得挂「运行中」，「告警」必须确有越限），缺项/不一致即中断，不用旧值顶替。
- **断点续导**：按文件内容哈希存检查点，取数中断后再次选择同一文件从断掉的那一条接着走，
  已落库行不回滚、不重放；换文件则从头开始。模板与「继续导入（n/m 行）」入口在主变页面。
- 逻辑自检：`cd frontend && npm run verify:transformer`（内存 localStorage 下跑 53 项断言）。
